# p99soft CMS (Strapi 5)

Content for p99soft.com. Only the BFF reads from it, using a scoped API token.

```bash
npm install
cp .env.example .env     # set real secrets
npm run develop          # http://localhost:1337/admin
npm run seed             # seed content, create BFF token and webhook (see root README)
```

Content types are generated by `scripts/gen-strapi-schema.mjs` in the repo root. Change the model there, then run:

```bash
node scripts/gen-strapi-schema.mjs apps/cms
```

Database: SQLite in `.tmp/` for local work. Use Postgres in every shared environment (`DATABASE_CLIENT=postgres`).
